<h1 align="center">code-hygiene-audit</h1>

<p align="center"><em>让垃圾代码活不过一个迭代。</em><br>
<sub>Shit mountains die young here.</sub></p>

<p align="center"><strong>一个防屎山清道夫 Skill</strong> · 适用于 ZCode / Claude Code 等编码代理</p>

---

## 为什么需要它

屎山的内核不是烂代码，是**真相分裂**——同一件事有两个以上的真相来源：两套配色 token、
两套信任逻辑、前端和服务端各算一遍的同一个数字。

AI 编码代理让这个问题变得更快：**它默认只生不杀**。迭代出新版，旧版原样躺着；
换个地方需要类似逻辑，就地抄一份而不是找共享函数。你越快，堆得越快。

靠嘱咐 AI「别写屎」没有用。有用的是机制：定期清点、证据说话、用户拍板、然后杀。
这个 Skill 就是把这套机制固化下来。

## 这是什么、给谁用

**给「和 AI 结对写码、迭代速度远超清理速度」的开发者**——尤其是一个人 + AI 的工作流。

当你的项目被连续生成了若干轮、或刚做完一次大改版/迁移，跑一次这个 Skill。
它会像清点仓库一样把代码库过一遍，产出一份**带证据的分级清单**：
哪里真相分裂了、哪里有死代码、哪里 UI 已经渲染坏了、哪里漂移出了 token 体系——
你看清单、拍板杀谁，它再动手。

**它不是**：linter（不查代码风格）、写码规范（那是 ponytail 类「决策梯子」Skill 的活）、
自动修复器（先报告后动手，价值一半在清单、一半在纪律）。

**边界**：死 UI 那一路需要环境里有浏览器工具（真实点开，不靠读代码猜）；
修复永远等用户确认，它自己不会先斩后奏。

## 五路扫描

| # | 扫什么 | 一句话判据 |
|---|---|---|
| ① | **真相分裂** | 同一件事将来要改，得改几处？>1 就是 |
| ② | **死代码** | 零引用的文件与导出、迭代残骸、注释尸骸 |
| ③ | **死 UI** | 浏览器真实点开，渲染损坏 = P0 |
| ④ | **漂移** | 硬编码色/魔法数偏离 token、黑话文案、假注释 |
| ⑤ | **陈旧产物** | 一次性脚本、临时报告、过期文档 |

产出 **P0 → P3 分级清单**（渲染损坏 → 真相分裂 → 漂移 → 死代码），
每项带证据（文件:行 / 截图 / grep 输出）和一句话修法。宁少报，不虚报。

完整扫描逻辑见 [SKILL.md](SKILL.md)，真实产出样例见
[examples/audit-report-example.md](examples/audit-report-example.md)。

## 实战绩例

来自一次真实审计（约 12 万行的 AI 写作工具，全栈，连续迭代两个月后）：

> 22 个弹窗逐一真实点开 + 全仓扫描，19 张截图存证：
>
> - **P0 ×2**：两个弹窗渲染彻底损坏（建书向导无遮罩不居中、标题重复渲染两遍；
>   书籍预览 dialog 丢样式内联压住榜单）——之前没有任何人发现，因为没人逐个点过
> - **P1 ×1**：聊天检索自己复制了一套信任逻辑，绕过了共享投影——用户在对话里
>   看到「基于事实」的无据引用
> - **P2**：三个品牌色系并存（默认绿 / 自定义暖棕 / 粉红），每个新页面随机站队
> - **P3**：约 725 行零引用死代码（4 个文件，都是上一版迭代的残骸）、
>   0 字空版本条目、写着「已下线」但还在跑的假注释

P1 那一条修复后成为后续 8 个逻辑缺陷修复的入口——真相分裂不清理，bug 会一直从同一个地方长出来。

## 安装

```sh
# 用户级（所有项目可用）
git clone https://github.com/Lazily01/code-hygiene-audit.git ~/.agents/skills/code-hygiene-audit

# 或项目级
git clone https://github.com/Lazily01/code-hygiene-audit.git .agents/skills/code-hygiene-audit
```

**触发**：直接说「帮我扫扫代码」「清一下屎山」「大改版完了看看留没留垃圾」，
或显式调用 `/code-hygiene-audit`。

## 搭配使用

写新代码前用「决策梯子」类 Skill（如 [ponytail](https://github.com/dietrichgebert/ponytail)）
管住**少生**；本 Skill 管**善杀**。一个管进嘴的，一个管排队的。
