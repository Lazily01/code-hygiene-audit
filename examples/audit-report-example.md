# 审计报告样例

来自一次真实审计的产出摘录（已脱敏：一个约 12 万行的 AI 写作工具，React 前端 + Python 后端，
被连续迭代两个月后做全量清点）。格式即本 Skill 的标准产出格式。

---

## 代码卫生审计 · 前端全量 · 2026-09-30

范围：Web 应用全部页面与弹窗（工作台 / 原稿房 / 编辑器 / 市场 / 世界观），1440×900 真实浏览器逐一点开，19 张截图存证。

### P0 · 渲染损坏（用户当场可见的坏）

- [ ] **短剧建书向导**：无遮罩、不居中贴右边缘；标题「说说你的想法」重复渲染两遍；表单芯片按钮无样式导致标签粘连；残留上一次未完成任务的提示条挤在标题下。
      证据：`GenWizardModal.tsx` + 截图 → 修法：补 dialog 样式层，标题取单一来源。
- [ ] **标杆书预览**：DOM 是 dialog，视觉上无遮罩、内联插在榜单下方并压住上方卡片；页头叠出一排空胶囊。
      证据：`BookPreviewModal.tsx` + 截图 → 修法：恢复 overlay 层与定位。

### P1 · 真相分裂

- [ ] **主色两套**：全局 token `--c-brand` 为默认绿（#10b981），工作台新页面自定义暖棕（#725039），每个新页面的主按钮颜色取决于引用了哪套。
      → 修法：改 token 单一来源，一处改动全站归队。
- [ ] **聊天检索复制了信任逻辑**：对话记忆注入没有走共享的审核投影，自己另查一份未审核数据，却以「基于作品事实」的名义注入。
      → 修法：检索与写作锚点共用同一投影与勘误覆盖层（该条后续牵出 8 个逻辑缺陷，全部同源）。

### P2 · 漂移

- [ ] 导入弹窗主按钮为粉色（#ec4899），脱离绿/棕双系——第三个色系。
- [ ] 首页书架徽章使用冷蓝 #354e5e，在暖色产品中按奇偶随机出现。
- [ ] 原稿房页头有绿色光晕装饰，与暖纸底色冲突。

### P3 · 死代码 / 陈旧产物

- [ ] `components/home/v2/{CreateBar,Feed,Markline,fx}.tsx` 约 725 行，全仓零引用（上一版迭代的残骸）。
- [ ] 历史版本抽屉里存在 0 字的空版本条目。
- [ ] 注释写着「已归档下线」但仍在运行时执行的假注释。
